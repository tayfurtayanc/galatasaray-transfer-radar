
# Galatasaray Transfer Radar Merkezi Plus

Bu sürüm direkt link üzerinden kullanmak için hazırlanmıştır.

## Eklenen Pro Özellikler

- Fabrizio Romano / Di Marzio / Matteo Moretto gibi kaynaklara ekstra güven puanı
- "Here we go" alarm sistemi
- KAP / resmi site kontrol alarmı
- Özel oyuncu takip listesi
- Oyuncu takip listesini panelden değiştirme
- Günlük transfer özeti
- İtalyanca / İngilizce / İspanyolca kaynak araması
- 5 dakikada bir otomatik yenileme
- Excel / CSV indirme

## Streamlit Cloud Kurulum

1. GitHub'da repo aç:
   galatasaray-transfer-radar

2. Bu ZIP içindeki dosyaları repoya yükle:
   - app.py
   - sources.json
   - watchlist.json
   - requirements.txt
   - README.md

3. https://share.streamlit.io adresine gir.

4. New app seç.

5. Repository:
   galatasaray-transfer-radar

6. Main file path:
   app.py

7. Deploy butonuna bas.
